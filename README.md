# Celebrity Kaiju Deathmatch

Open `index.html` in any modern browser.

- Battles restart every 1 minute (synced to real time).
- 30-second cooldown window with visible countdown timer.
- City destruction during fights.
- Claymation-style celebrity kaiju (procedural).
- Matchups rotate: Elviszilla, Alien Marilyn, etc.

Just open the file. Sound requires a click on some browsers.

Enjoy the chaos! ❤️
